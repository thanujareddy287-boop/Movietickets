# MovieBook Prototype

A mobile-style movie booking system prototype built with HTML, CSS and JavaScript.

## Included
- Splash screen
- Login / guest access
- Home screen
- Movie search and genre filters
- Movie details
- Date selection
- Theatre and show selection
- Seat selection
- Food/payment flow placeholder
- Payment confirmation simulation
- Digital ticket with booking ID
- Download ticket as TXT
- My Bookings
- Profile/settings UI
- Responsive mobile layout

## Run
Open `index.html` in a browser.

This is a frontend prototype. Payment, authentication, database, real theatre inventory, QR generation and backend APIs are simulated and can be connected later to Spring Boot + MySQL.
